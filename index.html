Что такое система уравнений

Определение. Система линейных уравнений с двумя переменными — это два уравнения вида ax + by = c, которые нужно решить одновременно.

{ y = 2x + 1
y = -x + 4

  • Решение системы — пара (x; y), удовлетворяющая обоим уравнениям
  • Систему записывают с фигурной скобкой {
  • Графический метод — построение графиков обоих уравнений на одной плоскости
💡 Запомни: точка пересечения двух графиков — решение обоих уравнений одновременно.
2

Алгоритм графического метода

Алгоритм:
  1. Выразить y через x в каждом уравнении (y = kx + b)
  2. Построить график первого уравнения
  3. Построить график второго уравнения
  4. Найти точку пересечения
  5. Записать координаты — это решение
  6. Проверить подстановкой
Пример пошагового решения

Система: { y = 2x + 1, y = -x + 4

  1. Уже выражены: y = 2x + 1 и y = -x + 4
  2. Для y = 2x + 1: при x=0 → y=1, при x=1 → y=3. Строим прямую.
  3. Для y = -x + 4: при x=0 → y=4, при x=4 → y=0. Строим прямую.
  4. Пересекаются в точке (1; 3).
  5. Ответ: (1; 3).
  6. Проверка: 3 = 2·1 + 1 ✓ и 3 = -1 + 4 ✓
🧮 Важно: графический метод даёт приближённое решение, если координаты не целые.
3

Три случая: сколько решений?

Количество решений зависит от взаимного расположения прямых:
  • 1 решение — прямые пересекаются (k₁ ≠ k₂)
  • 0 решений — прямые параллельны (k₁ = k₂, b₁ ≠ b₂)
  • ∞ решений — прямые совпадают (k₁ = k₂ и b₁ = b₂)
СлучайУсловиеГрафикПример
1 решениеk₁ ≠ k₂Пересекаются{ y=2x+1, y=-x+4 }
0 решенийk₁ = k₂, b₁ ≠ b₂Параллельны{ y=2x+1, y=2x-3 }
∞ решенийk₁ = k₂, b₁ = b₂Совпадают{ y=2x+1, y=2x+1 }
⚠️ Частая ошибка: если k₁ = k₂, это не всегда «нет решений». Проверь b!
4

Как построить график y = kx + b

Линейная функция y = kx + b — прямая. Для построения нужны две точки.
  • k — угловой коэффициент (наклон)
  • b — свободный член (пересечение с осью Y)
  • При k > 0 прямая вверх
  • При k < 0 прямая вниз
  • При k = 0 прямая горизонтальна
Пошаговое построение
  1. При x = 0 → y = b. Отметь (0; b).
  2. Выбери другое x (например, 1) и найди y.
  3. Отметь вторую точку.
  4. Проведи прямую через обе точки.

⭐ Преимущества и недостатки

  • Плюсы: наглядность
  • Плюсы: видно количество решений
  • Минусы: решение приближённое
  • Минусы: неудобно для сложных систем

🚫 Частые ошибки

  • Неправильно выразили y через x
  • Ошиблись в координатах точек
  • Неаккуратно построили прямые
  • Забыли проверить подстановкой
  • Путают k и b
